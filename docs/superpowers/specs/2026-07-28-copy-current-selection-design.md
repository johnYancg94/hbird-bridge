# 拷贝当前选区与按钮分层设计

## 目标

在 Hbird Bridge 底部操作栏新增“拷贝当前选区”，并将操作按钮调整为两行。第一行保留删除、新建文档打开、作为图层导入；第二行放置拷贝当前选区和智能对象导入。按钮分别使用红、蓝、青、橙、紫五种低饱和深色，确保窄面板内仍能快速区分。

## Photoshop 数据流

“拷贝当前选区”不依赖素材列表选择。点击后，CEP 通过 `evalScript` 执行一段独立 ExtendScript：

1. 确认 Photoshop 至少有一个打开文档。
2. 读取 `document.selection.bounds`，若抛出异常则判定没有有效选区。
3. 记录当前历史状态和活动图层。
4. 通过带 `Dplc=true` 的 `MrgV` 动作创建临时盖印可见图层，保留原图层结构。
5. 对临时图层执行 `copyToLayer`，将选区内容创建为新图层。
6. 对新图层执行 `selection.copy()`，等价于 Ctrl+C，将其写入系统剪贴板。
7. 删除临时盖印图层，保留新建的“选区拷贝”图层并设为活动图层。

## 错误与回滚

无文档、无选区、选区内无可见像素、盖印失败或剪贴板复制失败时，返回明确的中文错误信息。凡已开始修改文档的失败，均恢复到操作前的历史状态，避免遗留临时图层。脚本返回使用现有 JSON 兼容序列化器，避免 ExtendScript 缺少原生 `JSON` 的问题。

## 验证范围

自动验证包括 JavaScript 语法检查、按钮顺序和双行结构、五类颜色样式、事件绑定、无选区检查、非破坏盖印参数、选区新建图层、剪贴板复制、临时层删除及历史回滚。Photoshop 实机行为由用户在真实文档中验证。
