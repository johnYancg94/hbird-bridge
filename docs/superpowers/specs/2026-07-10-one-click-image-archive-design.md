# 一键图片归档功能设计

## 需求

在 Hbird Bridge Photoshop CEP 面板中增加两个功能：

- `📦 一键归档`：只重新扫描素材根目录，按 `LastWriteTime` 保留最新10张，将其余图片按周移动到素材根目录下的周归档文件夹。
- `📂`：在 Windows 资源管理器中打开当前素材目录。

根目录是唯一活动素材区；`images`、归档目录和其他素材包目录均不属于插件扫描范围，因此归档后的图片从面板消失。

## UI

- `📂` 紧跟素材目录选择按钮 `...`，使用相同的小按钮尺寸，提供 title 和 aria-label。
- `📦 一键归档` 位于“扫描文件夹”右侧和自动监听状态左侧。
- 归档期间禁用会修改素材状态的控件，完成后恢复。
- 执行前使用原生确认框显示总数、保留数、归档数和各目标周目录数量。

## 归档算法

1. 只重新异步扫描 `CONFIG.assetsDir` 根层。
2. 按 `mtimeMs` 降序排列；时间相同时按完整路径升序，确保结果稳定。
3. 保留前10张。
4. 剩余图片按周一至周日分桶。
5. 跨月周归属周四所在月份，即多数日期所在月份。
6. 月内周号从包含当月1日的周一开始计为第1周。
7. 文件夹名称为 `YYYY年M月第N周`。

示例：

- 2026-06-22 至 2026-06-28 → `2026年6月第4周`
- 2026-06-29 至 2026-07-05 → `2026年7月第1周`
- 2026-07-06 至 2026-07-12 → `2026年7月第2周`

## 安全与失败处理

- 所有目标必须解析到素材根目录的直接子目录。
- 移动前检查全部目标文件；同名但内容不同的文件追加 `__YYYYMMDD-HHmmss`，若仍重名则继续追加 `_2`、`_3`，不覆盖、不删除。
- 使用 `fs.rename` 在同一素材盘内移动，最多并发4项。
- 单项移动失败时记录失败，其他已计划项继续；失败文件保留原位。
- 移动后强制重新扫描并刷新卡片，状态栏显示成功、失败和保留数量。
- 图片不超过10张时不创建目录、不移动文件。
- 归档期间自动轮询跳过，防止与移动过程竞争。
- 打开目录使用 `child_process.execFile('explorer.exe', [CONFIG.assetsDir])`，不拼接 shell 命令。

## ADR：跨月周归属

**决定：** 使用周四所在月份作为周归属月份。

**理由：** 一个周始终进入一个文件夹；周四保证该周至少4天属于命名月份，并与“多数日期所在月份”一致。

**替代方案：** 使用周一所在月份会把 6月29日至7月5日命名为6月第5周；按每张图片自身月份会拆分同一周。两者均不采用。

## 测试

- 单元测试覆盖跨月周命名、稳定排序、保留10张、少于10张。
- 集成断言覆盖按钮顺序、事件绑定、Explorer 的 `execFile` 调用、归档确认和移动后刷新。
- 部署前后运行 JavaScript 语法检查并比较隔离副本、源包、安装版三方 SHA-256。
