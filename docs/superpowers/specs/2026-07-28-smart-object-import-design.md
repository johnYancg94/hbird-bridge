# 智能对象导入设计

## 目标

使用素材面板中选中的一张图片替换 Photoshop 当前图层，同时保持该图层在父文档中的位置、变换、蒙版和图层效果不变。

## 用户流程

1. 在 Photoshop 中选中要替换的图层。
2. 在插件中选择一张素材图片。
3. 点击“智能对象导入”。
4. 普通图层自动转换为智能对象；已有智能对象直接复用。
5. 插件打开智能对象内容文档，将素材等比缩放到完全覆盖画布并居中。
6. 原内容在新素材成功置入后删除。
7. 插件保存并关闭智能对象内容文档，返回父文档。

## 适配规则

- 素材和智能对象画布宽高比一致时，素材完整贴合画布。
- 宽高比差异超过 1% 时，保持比例、覆盖画布并居中裁切，状态栏明确提示。
- 每次只允许选择一张素材，避免一个目标图层对应多个替换结果。

## 失败处理

- 没有打开 Photoshop 文档、素材不存在或未选择素材时，不修改文档。
- 智能对象内容打开、置入、缩放或保存失败时，关闭未保存的内容文档并恢复父文档原历史状态。
- 只有新素材成功置入并完成适配后才删除原内容。

## 验证标准

- 普通图层可自动转换并完成替换。
- 已有智能对象可直接完成替换。
- 父文档中目标图层的外部位置和尺寸保持不变。
- 相同比例素材完整贴合；不同比例素材无空白并居中裁切。
- 失败流程不留下半完成的图层或未关闭的智能对象内容文档。
